# Oriba Sahar — Personal Portfolio

A responsive personal portfolio website built with **HTML5** and **CSS3**, styled around
a "full-stack layered architecture" visual concept, as part of the Full Stack
fundamentals challenge (HTML, CSS, Git/GitHub).

## 📖 About
This portfolio showcases my profile, skills, and projects as a full-stack developer,
with a hero section that visualizes the tech stack as layered bands (Database → Backend
→ Frontend → AI Layer).

Includes:
- **Hero section** — name, title, intro, and an animated layered-stack visual
- **About Me** — background and quick facts panel
- **Skills** — organized by layer (Frontend / Backend / Data / AI & Emerging / Tools)
- **Projects** — 4 project cards (Basecampy, EventHub, Expense Tracker, UI Clones)
- **Experience & Education** — timeline and certifications
- **Contact** — email, phone, LinkedIn, GitHub

## 🛠 Built With
- Semantic HTML5
- CSS3 (Flexbox, Grid, Media Queries, CSS custom properties/variables)
- Vanilla JavaScript (mobile nav toggle, scroll-reveal animations, copy-to-clipboard)
- Google Fonts (JetBrains Mono, IBM Plex Sans)

## 📱 Responsive Design
Tested and adjusted for desktop, tablet (900px), and mobile (760px and below), including
a collapsible mobile navigation menu.

## 🚀 Running Locally
1. Clone this repository:
   ```
   git clone https://github.com/your-username/your-repo.git
   ```
2. Open `index.html` in your browser — no build step or dependencies required.

## 📤 Deployment (GitHub Pages)
1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under "Build and deployment", set **Source** to your main branch, root folder.
4. Save — your site will be live at `https://your-username.github.io/your-repo/`.
